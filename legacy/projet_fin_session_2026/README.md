# Legacy - Projet de fin de session 2026

Ce dossier contient du code extrait du projet `Projet-de-fin-de-session-2026`.

Ces fichiers ne sont pas encore des modules génériques de librairie.
Ils servent de base pour extraire progressivement :

- gestion LCD
- lecture ADC
- conversion température
- UART debug
- timers
- historique
- contrôle d'états
- affichage série

À refactoriser avant utilisation directe dans un autre projet STM32.
