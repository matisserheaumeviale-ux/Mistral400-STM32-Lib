# Mistral400 STM32 Lib

Reusable STM32 HAL-based C library for embedded projects.

## Features

- LCD HD44780 16x2 / 20x4 support
- Button debounce helpers
- Timer utilities
- UART debug tools
- PWM helpers for fan control
- STM32 HAL compatible

## Target

Mainly tested with:

- STM32F103C8T6 Blue Pill
- STM32CubeMX / STM32 HAL
- ARM GCC
- VS Code / OpenOCD

## Structure

- `src/` : source files
- `include/` : header files
- `examples/` : usage examples
- `docs/` : documentation
